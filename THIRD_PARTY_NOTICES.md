repository for the Beyond Robotix Micro Node, STM32L431) contains software
written by third parties. Their copyright notices and licences are listed

include this file and the `licenses/` folder in the documentation or other

## Open issue: AllSensors_AUAV has no licence

`lib/AllSensors_AUAV` (copied from <https://github.com/BeyondRobotix/AllSensors_AUAV>)
has no licence file and no licence in its source. Without a licence, the right
to redistribute it is not granted. Before distributing this firmware, either
obtain a licence from the author or Beyond Robotix, or replace the driver with
Flowcopter's own implementation.

## How this list was made

The list covers what the linker actually placed in the binary, taken from
`.pio/build/Micro-Node-App/firmware.map` and traced back to each source
file's copyright header. Code that is compiled but not linked (for example the
`acanfd-stm32` driver in libArduinoDroneCAN, used only on H7 boards) is not
listed. Re-check this file when dependencies, the board or the toolchain change.

This file records licence obligations as read from the source files; it is not
legal advice.
